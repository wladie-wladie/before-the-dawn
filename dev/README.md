# Как устроен код

Игра собирается в одну страницу из модулей в `src/` (`python3 dev/mk.py` → `dev/out/page.html`).

**Движок — `src/core/`.** Ничего не рисует.
- `state.js` — состояние партии: мир `G` и все участники `G.P`. Человек и боты в одном формате, различаются полем `control`.
- `rules.js`, `time.js` — правила: карты, районы, слухи, дела Князя, время, сбор двора, рассвет, итог.
- `commands.js` — **все действия — команды**: `dispatch(id, "команда", {…})`. У каждой есть `can()`: `null` — можно, строка — почему нельзя. `options(id)` — что можно сделать сейчас, `cardsFor()` — какие карты подходят. Команда возвращает события (`emit`), по ним экран реагирует.
- `bots.js` — боты решают сами, но действуют теми же командами.

**Экраны — `src/ui/`.** Только рисуют и отправляют команды через `act()`.
- `app.js` — состояние экрана `UI` (камера, выбор, окна, путь), ходьба по шагам, отрисовка, сохранение.
- `map.js` — карта, `side.js` — правая колонка, `setup.js` — создание персонажа, `court.js` — сбор в Элизиуме, `overlays.js` — рассвет.

**Стили — `src/css/`**, по файлу на экран.

**Проверки — `dev/`.**
- `node dev/core-sim.js 20` — партии без интерфейса.
- `node dev/uiplay.js <страница> <клан> <шагов>` — игра нажимает кнопки, как человек.
- `node dev/baseline.js <страница> <папка> v2` — снимки всех экранов для сравнения «до/после».
