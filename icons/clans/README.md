# Значки кланов

Положите сюда файлы значков — игра покажет их на экране выбора клана вместо встроенных эмблем.

Имена файлов (подойдёт любой из форматов `.svg`, `.png`, `.webp`):

| Клан | Файл |
|---|---|
| Вентру | `ven.svg` |
| Тореадор | `tor.svg` |
| Носферату | `nos.svg` |
| Бруха | `bru.svg` |
| Тремер | `tre.svg` |
| Гангрел | `gan.svg` |
| Цимисх | `tzi.svg` |

Официальные символы кланов для фанатских проектов есть в наборе Dark Pack от Paradox Interactive. Используйте их по условиям этой лицензии. Уведомление о правах в подвале игры уже есть.
