# Значки

Все значки — силуэты на прозрачном фоне. Игра красит их в цвет клана или фракции через CSS-маску.

| Папка | Что внутри |
|---|---|
| `clans/<id>.png` | Символы кланов. В игре уже есть: ven, tor, nos, bru, tre, gan, tzi. Про запас: banu, caitiff, cappadocian, giovanni, harbingers, hecata, lamia, lasombra, malkavian, ministry, nagaraja, ravnos, salubri, thinblood |
| `clans/names/<id>.png` | Надписи-названия кланов |
| `../factions/` | cam, ana, sabbat, inquisition-leopold и их надписи в `names/` |
| `../disc/` | Дисциплины: animalism, auspex, blood-sorcery, celerity, dominate, fortitude, obfuscate, potence, presence, protean, alchemy, blank |
| `../dice/` | Кубы: normal-/hunger- с гранями blank, success, crit; hunger-skull |
| `../misc/ankh.png` | Анкх |

Чтобы заменить значок, положите файл с тем же именем.
