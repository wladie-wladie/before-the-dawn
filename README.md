# Before the Dawn

Неофициальная фан-игра по Vampire: The Masquerade. Не является официальным материалом World of Darkness. v0.3 «Город»: генерация ночного гекс-города и прогулка по нему. Прошлая версия с механиками — `intriga-v02.html`.

Играть: откройте страницу GitHub Pages этого репозитория и нажмите «Установить приложение» (Chrome/Edge/Android) или «На экран Домой» (Safari на iPhone).

Всё в одном файле `index.html`: числа, контакты, замыслы, указы и дела — в начале скрипта. При обновлении меняйте `VERSION` в `sw.js`.
